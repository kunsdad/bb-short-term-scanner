# BB 단기전략 스캐너 (시제품)

## 시작
```bash
pip install -r requirements.txt
python scanner.py
streamlit run app.py
```

## 자동화
GitHub 저장소에 파일을 올리면 `.github/workflows/daily.yml`이 한국시간 평일 16:30에 실행을 시도합니다. GitHub Actions 예약 실행은 지연되거나 누락될 수 있습니다. 한국 휴장일은 현재 명시적으로 판별하지 않으며 데이터 날짜를 확인해야 합니다. 데이터 수집 및 처리 소요 시간도 실제 시험이 필요합니다.

Streamlit Community Cloud 등에서 `app.py`를 배포할 수 있으나 GitHub 저장소의 데이터 업데이트와 배포 동기화는 별도로 검증해야 합니다. 공개 저장소에 올린 종목 분석 결과는 공개됩니다.

## 주의 및 미구현 사항
- 업종 상대강도는 신뢰할 수 있는 무료 업종 분류 및 지수 데이터가 확보되지 않아 미측정(0점)입니다. 따라서 총점 최대 9점이며 완전한 10점 평가가 아닙니다.
- 7점 이상, 당일 하단밴드 재진입, 유동성 확보, 밴드워크 아님, 손절가가 진입가 미만인 경우만 신규 후보로 분류합니다.
- 데이터 공급원 지연, 호출 차단, 종목 목록 구조 변경 가능성이 있습니다.
- 목표가·손절가는 단순 계산 예시이며 5일선/20일선이 유효 저항선인지 추가 검증해야 합니다.
- 공휴일 캘린더, 알림, 오류 재시도, 종목 수동 입력, 분할매수 비중, 전저점 정밀 탐지, 업종 상대강도, 정확한 10점 채점, 기업행위 보정 검증은 후속 개발 항목입니다.
- 실제 투자에 사용하기 전 백테스트와 모의 운영이 필요합니다.
